# 💰 Refund


Uma aplicação web desenvolvida para registrar despesas e calcular automaticamente o valor total dos reembolsos. O projeto demonstra conceitos fundamentais de desenvolvimento Front-end utilizando apenas tecnologias nativas da web.

## 🚀 Demonstração

🔗 **Acesse o projeto:**

https://cesarafael-cpu.github.io/Project-Refund-main/

---

# 📖 Sobre o projeto

O **Refund** é uma aplicação simples e intuitiva que permite adicionar despesas de diferentes categorias e visualizar automaticamente o valor total do reembolso.

O objetivo principal do projeto é praticar manipulação do DOM, eventos, funções em JavaScript e atualização dinâmica da interface sem utilizar frameworks.

---

# ✨ Funcionalidades

- ✅ Cadastro de despesas
- ✅ Descrição da despesa
- ✅ Categoria da despesa
- ✅ Valor da despesa
- ✅ Atualização automática da lista
- ✅ Cálculo automático do total
- ✅ Formatação em moeda brasileira (R$)
- ✅ Interface responsiva
- ✅ Manipulação dinâmica dos elementos HTML

# ⚙️ Como funciona

## 1. O usuário preenche:

- Nome da despesa
- Categoria
- Valor

↓

## 2. Ao clicar em adicionar

O JavaScript captura as informações do formulário.

↓

## 3. O sistema cria

Um novo objeto contendo as informações da despesa.

↓

## 4. A interface é atualizada

Uma nova linha é adicionada na lista.

↓

## 5. O total é recalculado

O valor total do reembolso é atualizado automaticamente.
